# 구현 기능 목록

## 1. 파일 입출력 기능

- [ ] `products.md` 파일을 읽어서 상품 정보를 파싱한다.
    - [ ] 상품명, 가격, 수량, 프로모션 정보를 분리한다.
    - [ ] 같은 상품의 프로모션 재고와 일반 재고를 구분하여 저장한다.
- [ ] `promotions.md` 파일을 읽어서 프로모션 정보를 파싱한다.
    - [ ] 프로모션명, buy, get, 시작일, 종료일 정보를 분리한다.
    - [ ] 날짜 형식(yyyy-MM-dd)을 LocalDate로 변환한다.

## 2. 재고 관리 기능

- [ ] 현재 보유하고 있는 상품 목록을 출력한다.
    - [ ] 프로모션 재고가 있는 경우 먼저 출력한다.
    - [ ] 일반 재고를 출력한다.
    - [ ] 재고가 0개인 경우 "재고 없음"으로 표시한다.
- [ ] 상품별 재고 수량을 관리한다.
    - [ ] 프로모션 재고와 일반 재고를 분리하여 관리한다.

## 3. 입력 처리 기능

- [ ] 구매할 상품과 수량을 입력받는다.
    - [ ] `[상품명-수량]` 형식으로 입력받는다.
    - [ ] 여러 상품을 쉼표(`,`)로 구분하여 입력받는다.
- [ ] 입력값의 유효성을 검증한다.
    - [ ] 상품명이 존재하는지 확인한다.
    - [ ] 수량이 숫자인지 확인한다.
    - [ ] 재고가 충분한지 확인한다.
    - [ ] 형식이 올바른지 확인한다. (대괄호, 하이픈 등)
- [ ] 잘못된 입력 시 `[ERROR]`로 시작하는 에러 메시지를 출력하고 재입력을 받는다.

## 4. 프로모션 적용 기능

- [ ] 현재 날짜가 프로모션 기간 내인지 확인한다.
- [ ] 프로모션 재고에서 우선적으로 차감한다.
- [ ] 프로모션 적용 가능 수량을 계산한다.
    - [ ] `buy + get` 단위로 묶을 수 있는 수량을 계산한다.
- [ ] 프로모션 혜택으로 증정되는 수량을 계산한다.
- [ ] 프로모션 재고 부족 시 정가 결제 여부를 확인한다.
    - [ ] 프로모션 미적용 수량을 사용자에게 안내한다.
    - [ ] Y/N 입력을 받아 처리한다.
- [ ] 추가 구매 시 프로모션 혜택을 받을 수 있는 경우 안내한다.
    - [ ] 1개 더 구매하면 증정품을 받을 수 있는 경우를 확인한다.
    - [ ] Y/N 입력을 받아 처리한다.

## 5. 결제 금액 계산 기능

- [ ] 총 구매액을 계산한다. (증정품 제외)
- [ ] 프로모션 할인 금액을 계산한다.
    - [ ] 증정품의 가격을 합산한다.
- [ ] 멤버십 할인 금액을 계산한다.
    - [ ] 멤버십 적용 여부를 입력받는다. (Y/N)
    - [ ] 프로모션 미적용 금액의 30%를 할인한다.
    - [ ] 최대 8,000원까지만 할인한다.
- [ ] 최종 결제 금액을 계산한다.
    - [ ] 총 구매액 - 프로모션 할인 - 멤버십 할인

## 6. 영수증 출력 기능

- [ ] 구매 상품 내역을 출력한다.
    - [ ] 상품명, 수량, 금액을 표시한다.
- [ ] 증정 상품 내역을 출력한다.
    - [ ] 증정 상품명과 수량을 표시한다.
- [ ] 금액 정보를 출력한다.
    - [ ] 총 구매액 (수량과 금액)
    - [ ] 행사 할인 금액
    - [ ] 멤버십 할인 금액
    - [ ] 내실돈 (최종 결제 금액)

## 7. 재고 차감 기능

- [ ] 구매 확정 시 재고를 차감한다.
    - [ ] 프로모션 재고를 먼저 차감한다.
    - [ ] 프로모션 재고가 부족하면 일반 재고를 차감한다.
- [ ] 증정품은 프로모션 재고에서 차감한다.

## 8. 추가 구매 기능

- [ ] 추가 구매 여부를 입력받는다. (Y/N)
- [ ] Y 입력 시 처음부터 다시 시작한다.
- [ ] N 입력 시 프로그램을 종료한다.

## 9. 예외 처리 기능

- [ ] 존재하지 않는 상품 입력 시 예외를 발생시킨다.
- [ ] 재고 수량을 초과하는 입력 시 예외를 발생시킨다.
- [ ] 잘못된 형식의 입력 시 예외를 발생시킨다.
- [ ] 잘못된 Y/N 입력 시 예외를 발생시킨다.
- [ ] 모든 예외는 `[ERROR]`로 시작하는 메시지를 출력한다.
- [ ] 예외 발생 시 해당 입력부터 다시 받는다.
