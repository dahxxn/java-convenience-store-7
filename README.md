# java-convenience-store-precourse

## 구현 기능 목록

### 프로모션 정보 등록하기

- src/main/resources/promotions.md 에 적힌 내용으로 프로모션 정보 읽어오기
- 프로모션명, 구매갯수, 얻는갯수, 시작날짜, 끝날짜로 구성된 열 읽으며 프로모션 DB 구성하기

### 상품 정보 등록하기

- src/main/resources/products.md 에 적힌 내용으로 상품 목록 읽어오기
- 상품명, 가격, 재고, 프로모션(없으면 null)로 구성된 열 읽으며 상품 DB 구성하기
    - 프로모션명에 해당하는 프로모션이 프로모션 DB에 존재하는지 확인 후 없다면 예외 발생하고 종료하기
        - 예외: "[ERROR] 잘못된 프로모션 정보입니다. 프로모션을 다시 설정해주세요. "

### 편의점 안내 메시지 출력하기

- "안녕하세요. W편의점입니다." 출력하기

### 편의점 현재 보유 상품 출력하기

- "현재 보유하고 있는 상품입니다." 출력하기
- 상품명, 가격, 재고, 프로모션 이름 안내하기
    - 만약 재고가 0개라면 `재고없음` 출력하기

### 구매할 상품과 수량 입력받기

- "구매하실 상품명과 수량을 입력해 주세요. (예: [사이다-2], [갑자칩-1])" 출력하기
- `[상품명-수량],[상품명-수량]...,[상품명-수량]` 형태로 구매할 상품과 수량 입력받기
- 상품과 수량을 잘못 입력한 경우, 오류 메시지 출력후 재 입력받기
    - 형식이 잘못된 경우: "[ERROR] 올바르지 않은 형식으로 입력했습니다. 다시 입력해 주세요"
    - 존재하지 않는 상품을 입력한 경우: "[ERROR] 존재하지 않는 상품입니다. 다시 입력해 주세요."
    - 구매 수량이 재고 수량을 초과한 경우: "[ERROR] 재고 수량을 초과하여 구매할 수 없습니다. 다시 입력해 주세요."
    - 기타 잘못된 입력의 경우: "[ERROR] 잘못된 입력입니다. 다시 입력해 주세요."

### 프로모션 적용 가능 상품 확인하기

#### 프로모션 할인 적용하기

- 오늘 날짜가 프로모션 기간 내에 포함된 경우만 진행하기
- N + 1 형태의 프로모션 진행하기
- 사용자가 담은 프로모션 상품의 갯수에 이슈가 있는경우 아래의 두 가지 분기에 따라 처리하기
- 프로모션으로 인해 얻게 되는 행사 상품과 그 갯수 정보기록하기

#### 프로모션 적용이 가능한 상품을 해당 수량보다 적게 가져온 경우, 추가 여부 입력받기

- "현재 {상품명}은(는) {갯수}개를 무료로 더 받을 수 있습니다. 추가하시겠습니까? (Y/N)" 출력하기
- Y 혹은 N으로 입력받기
    - Y를 입력하면 해당 수량만큼 프로모션 혜택에 추가하기
    - N를 입력하면 현재 상태 그대로 두기
    - 잘못된 입력의 경우: "[ERROR] 잘못된 입력입니다. 다시 입력해 주세요."

#### 프로모션 적용이 가능한 상품을 담아왔지만, 재고 부족으로 일부 수량을 프로모션 혜택 없이 결제해야하는 경우, 일부 수량에 대해 정가로 결제할지 여부 입력받기

- "현재 {상품명} {수량}개는 프로모션 할인이 적용되지 않습니다. 그래도 구매하시겠습니까? (Y/N)" 출력하기
- Y 혹은 N으로 입력받기
    - Y를 입력하면 해당 갯수만큼 정가로 구매하기
    - N를 입력하면 해당 수량만큼 제외하기
    - 잘못된 입력의 경우: "[ERROR] 잘못된 입력입니다. 다시 입력해 주세요."

### 멤버십 할인 적용 여부 확인하기

#### 멤버십 할인 적용 여부 입력받기

- "멤버십 할인을 받으시겠습니까? (Y/N)" 출력하기
- Y 혹은 N으로 입력받기
    - Y를 입력하면 멤버십 적용하기
    - N를 입력하면 멤버십 적용하지 않기
    - 잘못된 입력의 경우: "[ERROR] 잘못된 입력입니다. 다시 입력해 주세요."

### 멤버십 할인 적용하기

- 프로모션 미적용 금액의 30% 계산하기
- 해당 금액이 8000원을 넘어가면 8000원으로 멤버십 할인 금액을 고정하기

### 영수증 출력하기

- 상품명, 수량, 금액 으로 구성된 구매 상품 목록 출력하기
- 증정 칸에 프로모션으로 인해 얻게되는 상품명, 수량 목록 출력하기
- 총구매액 출력하기
    - 총 상품 갯수(구매 + 프로모션)와 해당 금액 출력하기
- 행사 할인 출력하기
    - 행사할인 금액 앞에 - 부호 붙여 출력하기
    - 행사 할인 금액은 프로모션으로 인해 얻게 되는 상품의 정가 합
- 멤버십 할인 출력하기
    - 멤버십 할인 금액 앞에 - 부호 붙여 출력하기
- 내실 돈 출력하기
    - 총 구매액 - 행사 할인 - 멤버십 할인으로 내실 돈 계산해 출력하기

### 상품 재고 관리하기

#### 프로모션 상품 재고 관리하기

- 해당 상품이 프로모션 기간인 경우, 프로모션 재고를 우선 차감하고 프로모션 재고가 부족할 경우 일반 재고 차감하기
- 프로모션 재고가 부족하면 일반재고 차감하기

#### 계산 후 재고 관리하기

- 상품명, 갯수 정보를 기반으로 상품 재고 차감하기
- 이때 행사 상품은 앞서 "프로모션 상품 재고 관리하기" 규칙에 맞게 처리하기

### 인사와 함께 추가 구매 유무 입력받기

- "감사합니다. 구매하고 싶은 다른 상품이 있나요? (Y/N)" 출력하기
- Y 혹은 N으로 입력받기
    - Y를 입력하면 앞의 과정을 다시 반복하기
    - N을 입력하면 시스템 종료하기
